Split into separate PDFs

The pieces are saved together as one zip. The document you are working on is left exactly as it is.

Stamp every page

One piece of text on every page: a watermark, a header, a footer or page numbers. Write {page} where the page number goes and {pages} for the total. Each stamp is ordinary added text afterwards, so any one of them can be dragged, retyped or removed.

Put a password on a copy

Saved with AES-256, which every reader since Acrobat X understands. The document you are working on is left exactly as it is, and nobody can recover this password for you.

This document needs a password

The password is used here and nowhere else. Nothing is sent anywhere, and it is not kept once the document is open.
